# Cover images drawn locally with Fooocus at draft time, committed to git

A new Post's cover image is drawn by the Writing Agent while drafting, through `pnpm cover`, which calls Fooocus (SDXL) running on the Owner's own machine, and the chosen image is committed into the Post's folder like any other image. Neither GitHub CI nor Vercel has a GPU, and a hosted image API would add a paid dependency and a secret for something the Owner reviews once per Post anyway; drawing at draft time also keeps the rule that nothing reaches Readers without the Owner's Review, because the image is part of the Draft PR. The style is chosen per Post from a short list the Owner approved from a side-by-side trial, so covers show what the AI can draw rather than one house style. The flip side: covers can only be made when Fooocus is running on that machine (otherwise the Post keeps its generated cover and the PR says so), a cover can't be redrawn in CI, and SDXL can't draw text, so a cover carries none.
