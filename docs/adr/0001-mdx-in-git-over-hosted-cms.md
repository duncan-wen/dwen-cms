# Content lives as MDX in git, not in a hosted CMS

Posts and Pages are MDX files in this repo rather than in Hashnode, Ghost or a database-backed CMS like Payload. Writing Agents work best editing files, and the Owner's Review happens as a pull request with full diff and history. MDX is also the only option that lets a Demo be embedded inside a Post. We give up Hashnode's community reach and Ghost's built-in newsletter and memberships; cross-post manually with a canonical URL if reach matters.
